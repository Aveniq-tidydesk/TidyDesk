# TidyDesk 1.0.0

Free native macOS file organisation with a simpler workspace and an interactive tutorial.

- Read-only folder scans with category counts, sizes and exact destination previews.
- Select individual files and explicitly confirm moves.
- Related-name/type matching with a custom destination folder.
- Saved Undo across app restarts, collision-safe filenames, cancellation and partial-failure reporting.
- Show moved files in Finder; local-only operation with no accounts, analytics or payments.

**Requires macOS 14 or later on Apple Silicon. Not Apple-notarised; ad-hoc signed only. Gatekeeper may block downloaded copies. Read the README before installing.**
